# Parcial 1 · v1.0.0

Aplicación web Next.js para el sistema BackArte7.

## Incluye

- CRUD de actores.
- Formulario para crear película, actor principal y premio, con asociaciones posteriores.
- Catálogo de películas con fecha, actor y premio.
- Página de detalle con atributos, reparto y premios.

## Ejecución

Consulta `README.md` para iniciar BackArte7 y la interfaz web.
